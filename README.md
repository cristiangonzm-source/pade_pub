# BetaPadelLab · publicaciones

Reels y Shorts de pádel animados en 3D con la física real de la bola, la pista y el cuerpo. Técnica, táctica y reglas en menos de un minuto.

Este repositorio **público** guarda lo que se publica: vídeo final y textos (`publicacion.md`) de cada reel, y los materiales del canal. El proyecto completo (motor, guiones, episodios) está en el repo privado `PADEL_PRIV`.

| Carpeta | Qué hay |
|---|---|
| `canal/` | Banner, foto de perfil y descripciones del canal (YouTube, Instagram, TikTok) |
| `04-saque/` | Reel «No saques para ganar el punto: saca para ganar la red» |

Regla: cada carpeta `NN-tema/` lleva el `.mp4` final y `publicacion.md` (título, descripción y etiquetas con SEO para YouTube Shorts, Instagram y TikTok). Se publica a mano.
